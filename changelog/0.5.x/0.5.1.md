# 0.5.1 — 2026-11-13

## Fixed

- **Alpine and Maven coordinates** resolve release-qualified Alpine PURLs and normalize Maven `group/artifact` to `group:artifact`. Incomplete Alpine or Maven coordinates return actionable errors, including per-row errors in batch queries. ([#47](https://github.com/cyanheads/osv-advisory-mcp-server/issues/47))
- **Advisory metadata** preserves ordered `upstream` IDs separately from `aliases` on all four advisory tools. Full detail also exposes `related` IDs and affected-entry `ecosystem_specific` and `database_specific` JSON, including through field retrieval. ([#48](https://github.com/cyanheads/osv-advisory-mcp-server/issues/48))
- **Composer PURLs** resolve to Packagist coordinates in single and batch queries, preserving repository scope for package-specific severity and fixes. ([#49](https://github.com/cyanheads/osv-advisory-mcp-server/issues/49))
- **Ecosystem matching** canonicalizes known base names case-insensitively and preserves suffix spelling. Invalid ecosystem errors point to `osv_list_ecosystems` at the original batch row. ([#50](https://github.com/cyanheads/osv-advisory-mcp-server/issues/50))
- **`osv_query_commit`** renders readable advisory sections with reversible JSON for complex or special values. Clean, incomplete, and exhausted-continuation notices appear on both response surfaces, and field retrieval retains the intact upstream cursor. ([#51](https://github.com/cyanheads/osv-advisory-mcp-server/issues/51))
- **Tool annotations** mark the four OSV-backed advisory tools with `openWorldHint: true`. The bundled ecosystem catalog advertises `false`. ([#52](https://github.com/cyanheads/osv-advisory-mcp-server/issues/52))
- **Batch field retrieval** keeps completed rows, recoverable findings and their continuation cursor at the shared operation deadline. `page.nextOffset` identifies the first unread row, and caller cancellation still propagates. ([#53](https://github.com/cyanheads/osv-advisory-mcp-server/issues/53))
- **Advisory guide 1.2** documents release and repository scope, upstream IDs for CVE lookup, and source metadata for remediation.
