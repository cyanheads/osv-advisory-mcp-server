# 0.5.0 — 2026-11-11

## Added

- **OSV continuation** returns a query-bound `nextCursor` for incomplete package, commit, and batch-row results. Resume batch rows with `osv_query_package` and repeat the input cursor when retrieving fields from a resumed result. ([#38](https://github.com/cyanheads/osv-advisory-mcp-server/issues/38))
- **`osv_query_batch`** accepts up to 5,000 packages and processes the first 1,000. Resubmit the unprocessed suffix from `summary.nextInputOffset`. Set `OSV_BATCH_SERVE_OVER_CAP=false` to enforce a 1,000-entry input limit. ([#40](https://github.com/cyanheads/osv-advisory-mcp-server/issues/40))

## Changed

- **OSV timeouts** default to 40 seconds per request attempt within a 50-second operation deadline for package, commit, and batch queries.
- **Packaging and development tooling** sync with the framework, preserve nested SDK runtime code in MCPB bundles, and require Bun 1.4.4 or newer for local development.

## Removed

- **Upstream error bodies.** Captured upstream error responses no longer expose `error.data.body` or `error.data.responseBody` to clients.
