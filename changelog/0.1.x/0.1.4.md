# 0.1.4 — 2026-06-04

**BREAKING:** The `osv_query` tool has been renamed to `osv_query_package`. Any client or agent calling `osv_query` by name must update to `osv_query_package` — the old name no longer exists. Input schema and output schema are unchanged; only the tool name changed. ([#2](https://github.com/cyanheads/osv-advisory-mcp-server/issues/2))

## Changed

- **`osv_query` → `osv_query_package`** — renamed for clarity: the tool name now explicitly identifies that it operates on a single package version, matching the batch counterpart's naming pattern (`osv_query_batch`). The implementation, input schema, and output schema are identical to the prior `osv_query`.
- **`osv-query.tool.ts` → `osv-query-package.tool.ts`** — source file renamed to match the new tool name.
- **`tests/tools/osv-query.tool.test.ts` → `tests/tools/osv-query-package.tool.test.ts`** — test file renamed accordingly; all 8 existing test cases updated to reference `osvQueryPackage`.
- All doc surfaces (`README.md`, `AGENTS.md`, `CLAUDE.md`, `docs/design.md`, `docs/idea.md`, `docs/tree.md`) updated to reflect the new tool name.
