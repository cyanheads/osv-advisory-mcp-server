# 0.1.14 — 2026-09-20

## Changed

- **Argument validation** — a rejected call now returns JSON-RPC `-32602` (`InvalidParams`) with `data.reason: "invalid_arguments"` and a synthesized recovery hint that also rides the `content[]` text as a `Recovery: …` line.
- **Tool error text** — an error carrying `data.reason` now closes its `content[]` text with a `(reason <reason>)` suffix.
- **Input normalization** — tool arguments pass a pre-validation step that drops client-added root keys and rewrites case-style key aliases before parsing; a normal call is unaffected.
- **Output schemas** — every tool's advertised `outputSchema` now carries the framework's discriminated error object alongside the success shape.
- **Cancellation** — a caller that disconnects mid-call now classifies as `RequestCancelled` (`-32011`) instead of an internal error.
- **HTTP session posture** — `createApp()` declares `sessionMode: 'stateless'` directly in `src/index.ts` rather than relying solely on the `MCP_SESSION_MODE` env default.
- **Repo hygiene** — development skills moved from `skills/` to `framework-skills/` so this server's Claude Code/Codex plugin no longer surfaces them to installing agents; CodeQL static analysis added as the project's one CI workflow.
