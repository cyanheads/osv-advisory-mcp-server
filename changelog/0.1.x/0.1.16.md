# 0.1.16 — 2026-10-08

## Changed

- **Tool error results carry `data.requestId`**, and `content[]` ends with `request <id>` (mcp-ts-core 0.13.10).
- **An integer sent for a string argument** (e.g. `version: 4`) is repaired to its digits before validation (mcp-ts-core 0.13.9).
- **Argument rejections** list at most 10 issue lines, then ` (+N more)` (mcp-ts-core 0.13.14).
- **`ctx.log` notifications** reach the client only at or above `MCP_LOG_LEVEL`, with sensitive fields masked (mcp-ts-core 0.13.11).
- **MCP SDK 2.1+ transports** refuse a 2026-07-28 POST without `MCP-Protocol-Version` with `400`/`-32020`, and a JSON-RPC batch over 100 messages (mcp-ts-core 0.13.9).
- **`osv_get_vulnerability` and `osv_query_package`** no longer forward `ctx.recoveryFor(...)` on their `ctx.fail` calls; the framework fills the declared recovery hint, and the hints callers see are unchanged. Their tests assert the hint through `runToolContract`.
- **Docker image** — dependencies install in a `deps` stage on `$BUILDPLATFORM`, so no Bun runs under QEMU (mcp-ts-core 0.13.10); musl-only packages are pruned from the image (0.13.11); base image is Bun 1.4.2 (0.13.7). `scripts/install-otel.ts` and `scripts/prune-musl-packages.ts` are new, and `.dockerignore` excludes every `.env*` file and the registry token files.
- **`server.json`** — npm entries drop the `run start:*` arguments and use `runtimeHint: "npx"`; the `streamable-http` entry sets `MCP_TRANSPORT_TYPE` to `"value": "http"` so it starts HTTP (mcp-ts-core 0.13.11).
- **`LOG_TOOL_FAILURE_PAYLOADS`** is documented in the README and `.env.example`, alongside the request-state, SSE resumability, log rate-limit, and OTLP endpoint variables.
- **Repo files** — `framework-skills/` and the `CLAUDE.md`/`AGENTS.md` agent protocol synced to 0.13.14; `scripts/` tooling (`devcheck`, `lint-mcp`, `lint-packaging`, `check-skill-versions`, `check-framework-antipatterns`, `release-github`) updated; `.gitignore` ignores `.env*` except `.env.example`, `.env.template`, `.env.sample`; `.mcpbignore` adds `.cache/`, `coverage/`, `tests/`, `docs/idea.md`, and `logs/`; `package.json` `files` excludes `dist/*.mcpb` and `packageManager` is `bun@1.4.2`; `.github/workflows/codeql.yml` runs once per language under its `/language:<language>` category; CONTRIBUTING, SECURITY, and the bug report form ask for shorter reports with credentials redacted.
