# 0.1.12 — 2026-07-11

## Changed

- **`osv_list_ecosystems`** — `SUPPORTED_ECOSYSTEMS` now mirrors the OSV schema's `ecosystemName` enum (49 names) plus `GIT` (50 total), replacing a stale 26-entry catalog; adds `Ubuntu`, `Azure Linux`, and 23 others, removes `GSD` (a vulnerability-ID prefix, not an ecosystem — OSV rejects it with HTTP 400). ([#12](https://github.com/cyanheads/osv-advisory-mcp-server/issues/12))

## Fixed

- **`osv_query_package`, `osv_query_batch`, `osv_get_vulnerability`** — blank and whitespace-only `name`, `ecosystem`, `version`, and `id` fields now fail schema validation instead of reaching OSV.dev, where they previously returned misleading errors or, worse, broader unintended matches. A blank row in `osv_query_batch` now fails the whole call's input validation rather than degrading to a per-row error. ([#10](https://github.com/cyanheads/osv-advisory-mcp-server/issues/10))
