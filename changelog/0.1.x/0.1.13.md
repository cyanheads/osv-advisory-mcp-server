# 0.1.13 — 2026-08-24

## Changed

- **MCP protocol support** — serves the 2026-07-28 protocol alongside sessionful 2025-era clients and rejects undeclared top-level tool keys before handlers run.
- **HTTP session mode** — self-hosted HTTP and the published container now explicitly use stateless mode; this server has no multi-round `ctx.requestInput` flow.
- **OSV request handling** — uses framework-managed timeouts, caller cancellation, transient retries, and `Retry-After`; HTTP 400 invalid-package queries and 404 advisory misses remain normal domain outcomes.
- **Build and packaging** — adopts Bun 1.4, TypeScript 7, split test/build typechecking, portable Docker builds, current validation and release tooling, synced agent skills, community contribution guidance, and 2026 copyright metadata.
