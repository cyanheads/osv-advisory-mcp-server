# 0.1.5 — 2026-06-12

Framework adoption release: `@cyanheads/mcp-ts-core` ^0.9.21 → ^0.10.6, with the error-code and packaging conventions that ship in 0.10.x.

## Added

- **Docker `HEALTHCHECK`** — probes `/healthz` every 30s via `bun -e fetch`, no `curl`/`wget` dependency.
- **OCI `image.version` label** — `Dockerfile` takes `ARG APP_VERSION` and stamps `org.opencontainers.image.version`.
- **`scripts/clean-mcpb.ts`** — post-pack `.mcpb` cleaner wired into the `bundle` script; runs `mcpb clean` then strips dependency-shipped agent-doc entries (`skills/`, `.claude/`, `.agents/`, `SKILL.md`) nested under `node_modules/` that root-anchored `.mcpbignore` patterns cannot reach.
- **`coerce-boolean-env-flag` rule** — `scripts/check-framework-antipatterns.ts` now flags `z.coerce.boolean()` on env flags (`Boolean("false")` is `true`); use `z.stringbool()`. Comment lines are skipped so documenting the pattern isn't a false positive.

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.21 → ^0.10.6` — adopts upstream framework changes.
- **`invalid_ecosystem` error code** — `osv_query_package` and `osv_query_batch` now throw `JsonRpcErrorCode.ValidationError` (`-32007`) instead of `InvalidParams` (`-32602`) for unrecognized ecosystem strings.
- **`createApp()` identity** — explicit `name` and `title` set to `osv-advisory-mcp-server` rather than relying on the npm-scoped package name fallback.
- **`.mcpbignore` patterns root-anchored** — `/skills/`, `/.claude/`, `/Dockerfile`, etc. now anchor to the bundle root instead of matching at any depth.

## Removed

- **`batch_too_large` error contract** — dropped from `osv_query_batch`; the input schema's `.max(1000)` already rejects oversized batches as a `ValidationError` before the handler runs, so a hand-written reason is redundant.

## Dependencies

- `typescript` `^5.9.3 → ^6.0.3`
- `@biomejs/biome` `^2.4.16 → ^2.5.0`
- `@types/node` `^25.9.1 → ^25.9.3`
