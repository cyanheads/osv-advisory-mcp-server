# 0.3.0 — 2026-10-18

## Added

- **`osv_query_package` and `osv_query_batch`** accept PURLs with exactly one embedded or separate version, preserving package-scoped fixes and severity. [#20](https://github.com/cyanheads/osv-advisory-mcp-server/issues/20)
- **`osv_query_commit`** queries full SHA-1 or SHA-256 Git hashes with record-wide severity, GIT ranges and bounded field retrieval. [#21](https://github.com/cyanheads/osv-advisory-mcp-server/issues/21)

## Changed

- **Batch package identity:** rows combining `name`/`ecosystem`/`version` with `purl`, previously accepted after discarding `purl`, now fail validation. Supply either the tuple or the PURL form.

## Fixed

- **Alias guidance** describes the CVSS scores and CISA KEV status available from `nist-nvd-mcp-server`. [#33](https://github.com/cyanheads/osv-advisory-mcp-server/issues/33)
- **Paging guidance** specifies overflow requests, continuation offsets/revisions and fresh deferred-child retrieval. [#34](https://github.com/cyanheads/osv-advisory-mcp-server/issues/34)
- **Test campaigns** measure thread CPU and allow complete reconstruction under host load while retaining content and CPU limits.

## Dependencies

- **`packageurl-js`** added at `^2.0.1` for standards-based PURL parsing.
- **`zod`** `^4.6.5` → `^4.6.7`.
- **`vitest`** `^5.0.3` → `^5.0.5`.
