# 0.2.0 — 2026-10-14

## Changed

- **Advisory responses** are bounded to 24,000 UTF-8 bytes across `content[]`, `structuredContent`, and enrichment. Oversized successes return preview/overflow arms; callers must follow same-tool `page` pointers instead of assuming complete inline fields. Fitting results retain their previous shape. ([#19](https://github.com/cyanheads/osv-advisory-mcp-server/issues/19), [#26](https://github.com/cyanheads/osv-advisory-mcp-server/issues/26), [#28](https://github.com/cyanheads/osv-advisory-mcp-server/issues/28))
- **Stateless pages** retrieve array/object entries and Unicode text slices with advancing offsets, deferred child pointers, and revision checks. Package advisory selection preserves scoped fixes/severity; batch pages fetch requested original-index rows without recomputing aggregate counts. Pages are fresh lookups, not saved snapshots.
- **`osv_query_batch`** uses positional `/v1/querybatch` preflight and one fetch per unique advisory, retaining package-scoped normalization, bounded rejection recovery, per-row truncation/errors, cancellation, and a 50-second scan deadline. ([#22](https://github.com/cyanheads/osv-advisory-mcp-server/issues/22))
- **Build and packaging** use Bun 1.4.2 → 1.4.3 and exclude repository-only source, scripts, documentation, and editor configuration from MCPB bundles; development guidance follows the adopted framework.

## Fixed

- **Advisory frame tokens** with recognized fullwidth delimiters or invisible separators render as visibly annotated text, including inside fenced code. Structured values remain verbatim; recognition covers a finite token set. ([#29](https://github.com/cyanheads/osv-advisory-mcp-server/issues/29))
