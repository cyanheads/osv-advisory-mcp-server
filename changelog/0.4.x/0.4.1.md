# 0.4.1 — 2026-10-31

## Added

- **Batch row memberships** retain ascending zero-based `summary.vulnerableRows`, `errorRows`, and `truncatedRows` through overflow, including overlapping outcomes; retrieve an index with `/results/<index>` ([#43](https://github.com/cyanheads/osv-advisory-mcp-server/issues/43)).

## Fixed

- **Package versions** reject npm/crates.io ranges and malformed exact versions, plus PyPI, RubyGems, and Maven constraints, before querying; `=` and `==` npm/crates.io pins normalize while OSV-compatible leading zeros remain valid ([#37](https://github.com/cyanheads/osv-advisory-mcp-server/issues/37)).
- **Package-scoped fixes and severity** match NuGet case variants, crates.io case and separator variants, and Red Hat Lightwell PyPI names across tuple, PURL, batch, and advisory retrieval ([#36](https://github.com/cyanheads/osv-advisory-mcp-server/issues/36)).
- **Caller coordinates** render literally in package notices, headings, batch rows, and retrieval pages while advisory HTTP(S) links remain usable; response sizing includes escaping ([#41](https://github.com/cyanheads/osv-advisory-mcp-server/issues/41)).
- **Overflow completeness** recognizes unchanged source fields retained in previews and leaves partial projections retrievable ([#44](https://github.com/cyanheads/osv-advisory-mcp-server/issues/44)).
- **Ecosystem discovery** includes Raspberry Pi OS and Red Hat Lightwell, bringing the live-verified catalog to 54 identifiers ([#12](https://github.com/cyanheads/osv-advisory-mcp-server/issues/12)).
