# 0.6.0 — 2026-11-20

## Added

- **Ubuntu binary resolution** maps installed binary names to their OSV source packages in single and batch queries. Incomplete fallback lookups are reported separately and excluded from clean counts. ([#60](https://github.com/cyanheads/osv-advisory-mcp-server/issues/60))

## Changed

- Release-qualified Ubuntu package queries that previously returned findings can now fail if OSV rate-limits source-package resolution or the mapping request exhausts the operation deadline.

## Fixed

- **Alpine PURLs** accept `alpine-`-prefixed numeric distro qualifiers and query the matching Alpine branch. ([#55](https://github.com/cyanheads/osv-advisory-mcp-server/issues/55))
- **Batch advisory field pages** return the underlying row lookup error when hydration fails, and callers can still retrieve the row diagnostic. ([#56](https://github.com/cyanheads/osv-advisory-mcp-server/issues/56))
- **Debian PURLs** normalize prefixed release numbers and codenames, preserve other qualifiers, and return recovery guidance for unknown explicit distros. ([#57](https://github.com/cyanheads/osv-advisory-mcp-server/issues/57))
- **Ubuntu PURLs** use numeric distro qualifiers to scope advisory lookup, fixed versions, and severity to the requested release. ([#58](https://github.com/cyanheads/osv-advisory-mcp-server/issues/58))
- **Advisory detail** preserves range-level `database_specific` metadata, including the release and tag evidence behind normalized ranges. ([#59](https://github.com/cyanheads/osv-advisory-mcp-server/issues/59))
